# FinFlow AI

Build a modern, premium SaaS frontend for an AI-powered Accounting Automation Platform designed for Pakistani SMEs.

The application should look like a professional product similar to Stripe Dashboard, Notion, QuickBooks, Linear, or Vercel. Use a clean minimalist design with soft shadows, rounded cards, blue and emerald color palette, responsive layout, beautiful charts, and smooth animations.

This is ONLY the frontend demo. Use realistic dummy data. No backend is required.
